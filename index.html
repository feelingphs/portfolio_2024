Introduce

이렇게 일합니다.

  • #사용자중심
  • #웹접근성
  • #유지보수
  • #협업
  • #성장
  • 기획 의도를 정확히 이해하고 사용자 관점에서 UI를 구현합니다. 더 나은 사용자 경험을 위해 필요한 경우 구현 방식을 제안하며 완성도를 높이기 위해 노력합니다.
  • 웹접근성을 기본 품질이라고 생각합니다. 시맨틱 마크업과 접근성 기준을 준수하며, 누구나 불편 없이 사용할 수 있는 서비스를 만들기 위해 꾸준히 고민합니다. 실제 프로젝트에서는 웹접근성 개선 및 품질인증 대응 경험을 보유하고 있습니다.
  • 재사용 가능한 구조와 일관된 마크업을 지향합니다. 다양한 예외 상황까지 고려하여 유지보수가 쉽고 확장 가능한 코드를 작성하기 위해 노력합니다.
  • 기획자, 디자이너, 개발자와 적극적으로 소통하며 프로젝트의 목표를 함께 이해하고 최적의 결과물을 만들기 위해 협업합니다.
  • 퍼블리싱이 완료된 이후에도 다양한 브라우저와 디바이스에서 반복적으로 테스트하며 작은 오류까지 놓치지 않는 완성도 높은 서비스를 만드는 것을 중요하게 생각합니다.
  • 8년간의 웹퍼블리싱 경험을 기반으로 React를 활용한 UI 개발 역량을 확장하고 있으며, 변화하는 기술을 꾸준히 학습하며 성장하고 있습니다.

현대백화점뉴스룸(Newsroom) 퍼블리싱

보도자료·브랜드 소식을 담는 뉴스룸 섹션의 목록·상세·필터 UI를 퍼블리싱했습니다. 방대한 콘텐츠가 매일 쌓여도 일관되게 보이도록,
재사용 가능한 컴포넌트와 접근성 구조를 기준으로 화면을 설계했습니다.

역할
뉴스룸 UI 퍼블리싱 ˙ 반응형 ˙ 접근성
기간
2026.05.02 - 2026.06.30
사용 기술
HTML5 ˙ SCSS ˙ JavaScript

주요 기여

  • 뉴스룸 목록 ˙ 상세 ˙ 카테고리 필터 화면을 시맨틱 마크업으로 구축하고 반응형으로 구현했습니다.
  • 제목 길이 ˙ 썸네일 비율이 제각각인 보도자료에 대응하는 유연한 카드/리스트 레이아웃을 설계했습니다.
  • 대체 텍스트 ˙ 헤딩 구조 ˙ 키보드 포커스 등 웹접근성 지침(KWCAG)을 반영했습니다.
  • Chrome ˙ Safari ˙ Edge 및 모바일 환경 크로스브라우징과 QA 이슈 대응을 담당했습니다.
  • 공통 컴포넌트와 퍼블리싱 가이드를 정리해 이후 콘텐츠 확장 시 유지보수성을 확보했습니다.
